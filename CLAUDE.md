# CLAUDE.md

## Privacy rule

This repository is public (it is deployed with free GitHub Pages). Never commit anything personal: no real names, contact details, photos, or the Learner's progress data. The Learner's chosen name lives only on his device. Messages to the Curator go through the device's share sheet, so no contact details are ever in the code.

## Agent skills

### Issue tracker

Issues live as local markdown files under `.scratch/<feature>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` plus `docs/adr/` at the repo root. See `docs/agents/domain.md`.
