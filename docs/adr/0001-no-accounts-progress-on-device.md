# No accounts or backend: Learner progress lives on his device

The aid has exactly one Learner, a minor, so we keep all progress in his browser's storage and offer a manual export/import backup instead of accounts and a sync server. A backend would mean storing a child's data on a server and adding real operational complexity, all to serve one person.

## Consequences

- iOS Safari wipes a site's stored data after 7 days without use when it runs in a normal browser tab; a web app added to the Home Screen is exempt. Because the Learner practises in irregular Bursts on iOS, the aid must steer him to install it on his Home Screen, and the export backup is the safety net.
- The Curator cannot see the Learner's progress remotely.
