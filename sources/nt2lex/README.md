# NT2Lex

`NT2Lex-CGN-v01.tsv` is NT2Lex, a list of how often each Dutch word appears in reading texts for
learners of Dutch at each CEFR level (A1 to C1). `npm run build:dictionary` uses it to pick the
Dictionary's words: single words that A1 and A2 texts use, most frequent first.
